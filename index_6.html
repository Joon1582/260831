Data Notes

데이터 노트

6종 원본 파일을 정제·대조한 방식입니다. 표기 불일치를 통일하고, 결측·이상치는 계산에서 제외하거나 별도로 표시했으며, PDF 원본 문서는 직접 판독해 수치를 추출했습니다.

customers_raw.csv · 648→600행
  • 중복 고객 48건 제거 (customer_id 기준)
  • 등급 표기 9종→5종, 지역 표기 19종→17종 통일
  • 예산 이상치(-1, 999999) 129건 결측 처리
consultations_raw.csv · 2,500행
  • 상담채널 표기 8종→4종 통일
  • 날짜 3개 포맷 ISO로 통일
  • 상담시간 이상치 718건(28.7%) 결측 플래그
  • 고객·매물 ID 불일치 레코드 154건(6.2%) 별도 표시
contracts_raw.csv · 350행
  • 상태 표기 6종→3종 통일
  • 날짜 4개 포맷 ISO로 통일
  • 대출금액 결측 41건(11.7%) 플래그
  • 분양가 0원 4건 결측 처리
units.csv · 220행
  • 결측·이상치 없음
  • 동/호/타입/가격/상태 기준 테이블로 사용
ad_spend.csv · 144행
  • 24개월 × 6채널, 결측·이상치 없음
  • 수치형 캐스팅만 수행
docs/*.pdf · 13개 문서
  • 분양계약서 원본 샘플 12건 — pdfplumber로 계약자·매물·분양대금 판독
  • 건축물대장 발췌 1건 — 동/세대수 구조 판독
