# Track 2 Mission — 데이터셋 안내

> 본 폴더의 모든 데이터는 **100% 합성(가상) 데이터**입니다. 실제 고객·계약·건물과 무관하며,
> 이름·연락처·주소·금액 등 모든 값은 실습을 위해 무작위로 생성되었습니다.

## 미션 개요

"매출로 이어지는 AI 고객 관리" 실습 A·B(엑셀 정리·문서 판독·CRM 대시보드 배포)에서 배운 내용을
**새로운 데이터셋**에 스스로 적용해 보는 과제입니다. 강의 실습 때보다 데이터 양이 많고,
표기 방식도 통일되어 있지 않습니다 — 실무에서 받는 데이터가 원래 이렇습니다.

## 파일 구성

| 파일 | 행 수 | 설명 | 정리가 필요한 이유 |
|---|---|---|---|
| `customers_raw.csv` | 648행 | 고객 명단 (등급·유입경로·관심타입) | 중복 고객(다른 전화번호 포맷) · 등급 표기 불일치(VIP/vip/일반 ) · 결측 이메일·전화 · 예산 이상치(-1, 999999) |
| `units.csv` | 220행 | 매물(세대) 마스터 — 동/호/타입/가격/상태 | 비교적 정돈됨. 다른 표와 조인하는 기준 테이블 |
| `consultations_raw.csv` | 2,500행 | 상담 이력 | 날짜 포맷 3종 혼재 · 채널 표기 불일치(전화/phone/Phone) · 존재하지 않는 customer_id·unit_id 일부 포함 · 상담시간 이상치(음수, 0, 240분) |
| `contracts_raw.csv` | 350행 | 계약 이력 | 상태 표기 불일치(완료/complete/Completed) · 대출금액 결측(약 12%) · 분양가 0원 이상치 일부 |
| `ad_spend.csv` | 144행 | 24개월 × 6채널 광고비·유입 | 비교적 정돈됨. 채널별 리드·전환 분석용 |
| `docs/contract_sample_01~12.txt` | 12개 | 합성 분양계약서 텍스트 | 문서 판독(정보 추출→표/JSON) 실습용 |
| `docs/building_registry_sample.txt` | 1개 | 합성 건축물대장 발췌 | 문서 판독 실습용 |

## 미션 요구사항

1. **데이터 정리**: `_raw` 파일의 중복·표기 불일치·결측·이상치를 정리하고, 무엇을 어떻게 처리했는지 **처리 로그**를 남길 것
2. **데이터 테이블**: 정리된 데이터를 Supabase(또는 동급 DB)에 적재
3. **대시보드 시각화**: 위 데이터를 바탕으로 한 대시보드를 웹에 배포 (핵심 지표 + 최소 3개 이상 시각화)
4. **인사이트 분석**: 대시보드 안에 **구조화된 인사이트 섹션**을 포함 — 각 인사이트는 "발견 → 근거 데이터 → 제안 액션" 3단 구조
5. **배포**: GitHub → Vercel로 배포하고 **공개 링크**를 제출

세부 제출 형식과 평가 기준은 슬라이드 자료의 "Track 2 Mission" 페이지를 참고하세요.
